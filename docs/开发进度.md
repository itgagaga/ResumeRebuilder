| 阶段 | 实现 | 验证 |

## 验收记录

- TypeScript 检查和 Vite 生产构建通过；加入页面内编辑后 JS 约 284KB（gzip 约 87KB）。
- 后端自动测试覆盖真实解析/OCR、工程存储/重开、HTML 转义、PDF 文本/图片/不同纸张与单位、CropBox 坐标、透明图片、非法资源、跨站访问和 ZIP 路径/体积校验；图片样式更新后另加入色块、字体/字重、文字宽度、圆点缩进、局部样式安全及 RGB 输入契约测试。
- `scripts/verify_ui.py` 使用本机 Edge 完成实际操作；没有页面 JavaScript 错误或前端外部请求。
- 视觉检查后修复双击文字被画布指针捕获拦截的问题，并增加源字体字宽估计，避免示例原文在后备字体下初始换行。
- 成品的 HTML/PDF 标题使用固定「简历」，避免来源工程名/文件名中的旧姓名进入成品元数据。
- OCR 模型 SHA-256 与安装包的模型许可证声明一致。浏览器运行时验证采用现有 Edge；完整 Chromium 下载较慢，已取消该下载，安装脚本支持 `-BundleBrowser` 后续提前打包。
- 没有使用真实用户简历进行测试；全部样例为项目自行生成的虚构内容。
- 后续样式修复额外使用用户本次提供的原图进行本机私有验收；该图片不加入仓库或固定测试集，相关数据只写入忽略版本管理的 `artifacts/image-quality/`。
- 图片样式修复后的最终回归为 31 项通过；原图验收恢复 42 行文字、8 个标题装饰形状、7 个列表圆点。实际 React 编辑器与导出 HTML 的初始溢出均为 0，局部粗体文字改写后保存通过；该结果只针对本次样例，不保证任意图片精确还原。
- 页面编辑交互改为真正的 contenteditable HTML 节点，保留光标和局部字重；右侧文本输入作为辅助。新增自动扩展、固定宽度增高、固定尺寸三种模式，以及增高时推开下方内容的开关。状态与导出窗口提示越界；跨页重排仍未实现。`scripts/verify_inline_editing.py` 在隔离 API 中验证实际输入、中文 IME、粗体、换行、撤销及保存导出。
- 页面内编辑的浏览器验收通过：短追加不换行、扩宽、长内容换行增高与下移、光标、撤销/重做、辅助侧栏、固定模式、Enter/空行、中文组合输入、Ctrl+B、粗体保留、纯文本粘贴、工程重开及 PDF。对应后端 31 项回归通过。
- 离线验证采用程序级网络阻断；实际操作系统断网与更多模板的视觉误差统计尚待人工验收。

## 数据与代码位置

- `backend/models.py`：唯一后端模型，拒绝额外字段与非法样式；`frontend/src/types.ts` 对应前端类型。
- `backend/parser.py`：原生 PDF 与图片路径选择、几何与文字分组；`backend/ocr.py`：显式本地模型路径。
- `backend/image_layout.py`：像素色块/线条、文字颜色、字体/粗体、圆点与缩进估计；`backend/font_metrics.py`：使用本地浏览器校准编辑器与成品的文本宽度。
- `backend/storage.py`：原始参考/用户资源分离、原子 JSON 保存、安全工程 ZIP。
- `backend/exporter.py`：只从当前模型生成 HTML/PDF，共用几何、字宽、裁剪与圆角规则。
- `backend/main.py`：API、仅本机与可信 Origin 限制、180 秒独立解析进程。
- `frontend/src/Canvas.tsx`：指针操作、内联文字编辑、溢出检查；`SourcePreview.tsx`：手动框选；`Inspector.tsx`：属性；`App.tsx`：会话历史与流程。
- `frontend/src/InlineTextEditor.tsx`：可见页面的光标编辑；`textEditing.ts`：纯文本与局部字重映射、字体度量、文字扩容和局部下移。
- `setup.ps1` / `start.ps1`：Windows 安装/启动。
- `docs/dependencies.json` / `docs/licenses/`：锁定环境的依赖元信息和许可证原文。
