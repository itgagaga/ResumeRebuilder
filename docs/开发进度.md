## 验收记录

- TypeScript 检查和 Vite 生产构建通过；JS 约 276KB（gzip 约 85KB）。
- 后端 25 项自动测试覆盖真实解析/OCR、工程存储/重开、HTML 转义、PDF 文本/图片/不同纸张与单位、CropBox 坐标、透明图片、非法资源、跨站访问和 ZIP 路径/体积校验。
- `scripts/verify_ui.py` 使用本机 Edge 完成实际操作；没有页面 JavaScript 错误或前端外部请求。
- 视觉检查后修复双击文字被画布指针捕获拦截的问题，并增加源字体字宽估计，避免示例原文在后备字体下初始换行。
- 成品的 HTML/PDF 标题使用固定「简历」，避免来源工程名/文件名中的旧姓名进入成品元数据。
- OCR 模型 SHA-256 与安装包的模型许可证声明一致。浏览器运行时验证采用现有 Edge；完整 Chromium 下载较慢，已取消该下载，安装脚本支持 `-BundleBrowser` 后续提前打包。
- 没有使用真实用户简历进行测试；全部样例为项目自行生成的虚构内容。
- 离线验证采用程序级网络阻断；实际操作系统断网与更多模板的视觉误差统计尚待人工验收。

## 数据与代码位置

- `backend/models.py`：唯一后端模型，拒绝额外字段与非法样式；`frontend/src/types.ts` 对应前端类型。
- `backend/parser.py`：原生 PDF 与图片路径选择、几何与文字分组；`backend/ocr.py`：显式本地模型路径。
- `backend/storage.py`：原始参考/用户资源分离、原子 JSON 保存、安全工程 ZIP。
- `backend/exporter.py`：只从当前模型生成 HTML/PDF，共用几何、字宽、裁剪与圆角规则。
- `backend/main.py`：API、仅本机与可信 Origin 限制、180 秒独立解析进程。
- `frontend/src/Canvas.tsx`：指针操作、内联文字编辑、溢出检查；`SourcePreview.tsx`：手动框选；`Inspector.tsx`：属性；`App.tsx`：会话历史与流程。
- `setup.ps1` / `start.ps1`：Windows 安装/启动。
- `docs/dependencies.json` / `docs/licenses/`：锁定环境的依赖元信息和许可证原文。

保持原约束：不得引入付费在线 AI；不得把源头像或整页原图放入编辑版/成品；文字必须是真实可修改的对象，导出不得夹带旧原文。
