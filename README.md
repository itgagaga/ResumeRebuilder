# Resume Rebuilder · 简历重建工作台

根据 [开发文档.md](开发文档.md) V1.1 实现的本地首版。Python + FastAPI 负责解析、OCR、存储和导出；React + TypeScript 渲染 HTML/CSS 编辑页面。文件保存在本机 `projects/`，服务只监听 `127.0.0.1:8765`。

## 启动

本次开发已安装 Python / 前端依赖并构建界面，当前机器的 Edge 已验证能用于 PDF 导出。在此文件夹的 PowerShell 中运行：

```powershell
.\start.ps1
```

浏览器访问 <http://127.0.0.1:8765>。按 Ctrl+C 停止服务。不自动打开浏览器时使用 `.\start.ps1 -NoBrowser`。

也可以通过根目录的 Python 启动文件运行（自动使用项目虚拟环境）：

```powershell
python run.py
# 不自动打开浏览器
python run.py --no-browser
```

换到新环境时先安装 Python 3.11～3.13、Node.js 22（建议安装 uv），再运行：

```powershell
.\setup.ps1
.\start.ps1
```

安装阶段需要下载依赖；应用运行阶段没有在线 AI、云服务、远程字体或模型下载。安装脚本默认优先使用现有 Edge/Chrome，找不到时安装项目内的 Chromium headless shell。若准备独立离线运行时，可执行 `.\setup.ps1 -BundleBrowser` 提前下载浏览器。Python 依赖和 OCR 模型必须提前安装；此版本尚未制作无需 Python/Node 的安装包。

若本机 PowerShell 执行策略禁止脚本，可从本目录使用 `powershell -ExecutionPolicy Bypass -File .\start.ps1`，仅影响该脚本进程。

## 使用

1. 点击「导入简历模板」选择 PDF、JPG、PNG、WebP；也可以拖入文件。点击「体验示例」打开两页合成简历。
2. 左侧是原始参考，右侧是真实的文本、线条、矩形和图片占位框。原生 PDF 提取文字和图形；图片/扫描 PDF 使用本地 OCR，需人工校对。
3. 默认「内容编辑」：单击简历文字，在点击的位置放置光标；拖过文字选择后可直接替换、复制或粘贴。Tab / Shift+Tab 切换文字块；点击空白处或按 Escape 结束。也可点右侧「在页面中编辑」，右侧输入框用于辅助校对。
4. 切换「版式调整」后，可拖动元素或八个尺寸手柄，双击文字仍可输入。左侧工具栏可绘制文字、图片区域、矩形和线条。
5. 截图中的头像未自动定位时，选择「框选图片区」，在左侧原页拖出矩形或椭圆区域。新占位框不会自动删除重叠的 OCR 文字；右侧会提示你人工检查。
6. 选择图片区，在属性栏上传自己的 JPG/PNG/WebP。可以切换矩形、圆形/椭圆、圆角、cover/contain，调整缩放与水平/垂直裁剪定位；清除图片会保留框。
7. 点击「保存」写入本地工程；首页可打开最近工程。导出 `.rresume` 工程包便于备份、迁移和重新打开，勾选是否包含原始参考。
8. 导出 PDF 或可独立编辑的 HTML。导出会先保存当前工程。HTML 下载为 `resume-editable.html`，双击用浏览器打开即可改文字、加粗、更换图片、保存新 HTML 和打印 PDF，无需运行工作台服务。PDF 成品不包含编辑工具。未替换图片区会提示，PDF 中保留空白、背景和边框；HTML 中提供可点击的更换入口，打印时不输出占位提示。

快捷键：V 选择、T 文字、I 图片、R 矩形、L 线条；Ctrl+S 保存、Ctrl+Z 撤销、Ctrl+Y / Ctrl+Shift+Z 重做、Ctrl+D 复制、Ctrl+C / Ctrl+V 复制粘贴所选对象、Delete 删除、方向键微移，Shift+方向键移动 10 个页面单位。文本输入框中保留正常的文字编辑快捷键。

页面内编辑支持中文输入法、Enter 换行、文本复制粘贴，Ctrl+B 可切换选中文字的粗体。默认「内容增长」会扩展文字框到当前可用宽度，再换行增高；增高时推开同栏下方内容。可选「固定宽度 / 换行增高」或「固定尺寸 / 手动调整」。手动拖动文字框尺寸后使用固定宽度模式。撤销/重做同时恢复文字与位置变化。自动扩展保留原有空白，不会因清空文字而折叠模板。

正文被识别为一行一个对象时，点击「整理正文为段落」，预览当前页的连接候选后应用；Ctrl+Z 可整体还原。也可选中一行，使用右侧「与下一行合成段落」。合并去掉识别产生的换行边界，保留局部粗体，中文连续连接、英文单词间补空格。段落使用固定宽度自动换行，增删文字时自动增减高度，并带动下方栏目、标题装饰及后续内容移动。空段落保留一行可输入区域。

段落整理按距离、对齐、文字长度和样式判断，默认跳过短标题、编号列表、独立圆点列表、并排日期、不同样式及已整理的段落。这是保守的版面规则，不会自动理解任意模板的语义，应用后需对照检查。单行也可直接把「内容增长」设为「段落 / 自动增减高度」；其余三种模式继续保留模板空白。

### 独立 HTML 文件的编辑与保存

导出后直接用浏览器打开 `.html` 文件，点击文字即可输入，选中文字后点击「加粗 / 取消加粗」或按 Ctrl+B。点击图片区域选择本机 PNG/JPG/WebP；图片会嵌入文件，不依赖外部资源。顶部「文字排版」可调整当前文字块的增长方式，段落模式支持高度增减和下方内容顺移。

点击「保存修改后的 HTML」或按 Ctrl+S，浏览器会下载包含当前文字、格式和图片的新文件；打开这个新文件还可以继续编辑和再次保存。保存不会自动覆盖最初的文件。输入与新图片保留在当前页面内，关闭前请保存。文件中的修改不会自动同步回工作台工程，目前也不支持将 HTML 重新导入工程。

「打印 / 导出 PDF」调用浏览器打印，可选择另存为 PDF。编辑工具、焦点框和空图片提示不会进入打印。内容变长时屏幕上的页面随之增高，打印时每个原始页面等比缩小到其纸张尺寸；这与自动拆成更多页面不同，长文可能使字号变小。不同栏、固定尺寸和旋转文字仍需检查。

## 隐私与数据

- 导入默认保留原文，修改直接更新 `Element.text`，没有原图底图、白色遮罩或旧文本覆盖层。
- PDF 源图片只读取显示位置，不解码到素材库；整页扫描图进入 OCR 路径，不生成整页头像框。
- 原始页面会渲染到 `reference/` 供对照，可能含原个人信息。点击原始参考面板的删除按钮可永久清除参考，同时清空撤销历史。
- `assets/` 只接收用户主动上传的新图片；图片重新编码为 PNG，保留透明度、应用 EXIF 方向并剥离元数据。
- PDF/HTML 只读取当前元素与引用的新图片，不包含原始参考、撤销历史或未引用的图片。
- 成品标题使用固定「简历」，不把来源文件名写入 HTML/PDF 元数据；工程包仍保留你当前设置的工程名称。
- 撤销历史只在当前浏览器页面的内存中；解析提示面板提供「清空撤销历史」。保存与工程导出不持久化历史。
- 导出工程包可取消原始参考。工程包包含当前 JSON 与已引用的新图片；重新导入会分配新工程 ID。
- 文件上限 25MB，图片上限 3000 万像素，最多 20 页；项目包解压总量上限 100MB。路径穿越、重复路径、非法文件、非法资源和颜色/字体注入会被拒绝。
- 源文件解析在独立进程执行，超时 180 秒；错误导入不会覆盖已有工程。数据目录可通过 `RESUME_DATA_DIR` 配置，浏览器路径可通过 `RESUME_BROWSER_PATH` 配置。

## 当前边界

已覆盖 M0～M4 的基础工作流。复杂 PDF 裁剪、曲线、遮罩、缺失字体仍需人工校正；OCR 的颜色、字体和布局估计不是精确恢复。PDF 原字体名称会保留为线索，使用系统后备字体，并估计字宽以保持原行边界；换机器后应再次检查排版。

图片/扫描页已增加像素样式重建：纯色标题背景、横线/竖线和列表圆点成为可编辑图形；根据实际文字像素估计颜色、字号、整行与局部粗体，使用本地浏览器度量校准编辑器及导出宽度。局部样式只记录当前文字的索引范围，页面内编辑保留局部粗体，辅助输入框按改动映射未修改范围；选择整框字重可统一重设。不保存旧文字副本。字体细节、图标与 OCR 误读仍需要校对。

图片重建按通用像素和几何特征处理，不按来源文件名、人员姓名、特定技术词或模板坐标分支。低置信度行会在本地局部复识别，未能确认的行在画布上标记并提示；不会把几个缺字结果强行拉伸铺满长行。中文和英文字体分别匹配，同一行共享字号；清晰证据可保留不同标题字体，页面统计仅用于消解模糊候选。样式估计失败时保留已识别的文字和位置，并提示人工校正。灰色细分隔线和不同大小的列表圆点也按几何恢复。

字体仍是本机已安装字体中的近似候选。小字号经过缩放/JPEG 压缩后会丢失字体细节，OCR 文字正确并不代表字体准确；候选不明确时，解析提示和属性栏会明确说明。当前没有达到任意简历图的像素级还原，也不能把某张图片的成功验收推广到所有模板。

升级后请重启后端、刷新前端，再重新导入原图。已经保存的工程保留此前的元素数据，不会自动重跑识别或覆盖你的修改。

页面内编辑与自动扩展功能可直接用于已有工程，无需重新导入；重新导入仅用于重新运行图片识别及样式恢复算法。

单击编辑和段落整理可直接用于已有工程，无需重新导入；升级后必须重启后端并刷新前端，新后端才支持保存段落模式。整理仅在用户应用时修改当前页，可以撤销。

当前用 HTML DOM 编辑段落，页面仍按模板坐标存储；支持单页内的段落增减高度与后续内容顺移，尚非整篇文档的连续流式排版，不自动跨页重排，也不支持跨独立文字块一次删改。复杂多栏或旋转文字需手工校正。超出纸张时状态栏和成品导出窗口会提示，导出前请逐页检查；工作台直接导出的 PDF 仍按原纸张边界裁切。独立 HTML 已内置编辑与保存能力，其浏览器打印会将增长后的每页内容缩小到原纸张；它不包含工程的原始参考和撤销历史。

P1 的自动候选图片区检测、多选对齐、吸附、差异叠加、批量清空、整篇跨页流式排版和安装包尚未实现。源头像的复杂圆形裁剪由用户在属性栏手动校正。

## 开发与验证

```powershell
# 后端开发
uv run uvicorn backend.main:app --host 127.0.0.1 --port 8765 --reload
# 新终端中启动前端开发服务器
cd frontend
npm run dev
```

前端开发地址为 `127.0.0.1:5173`，API 通过 Vite 代理到 8765。正式启动使用已经构建的 `frontend/dist/`，无需 npm 运行。

```powershell
.\.venv\Scripts\python.exe -m pytest -q
# 先启动本地服务，再执行真实浏览器验收
.\.venv\Scripts\python.exe scripts/verify_ui.py
.\.venv\Scripts\python.exe scripts/check_runtime.py
cd frontend
npm run build
```

测试样例均为自行生成的虚构内容：`examples/native-resume.pdf`（两页原生 PDF + 合成头像）、`chinese-resume.png`（中文截图）、`scanned-resume.pdf`（整页扫描）、`repeated-photo.pdf`（同一图像资源多位置）。生成脚本为 `scripts/create_samples.py`。这些样例可以自由用于本项目的验收。

真实浏览器脚本验证编辑、撤销、拖动、图片上传/裁剪、工程重开、手动区域、溢出与分页，并检查导出的 PDF；截图和导出测试文件保存在忽略版本管理的 `artifacts/`。网络验证是禁止 OCR 网络调用、阻断导出页面网络请求、检查前端外部请求；尚未进行操作系统断网开关的人工测试。

指定图片的样式与整页浏览器验收可运行 `.\.venv\Scripts\python.exe scripts/verify_image_layout.py "图片路径.png"`，生成私有原图对照、编辑器截图及 PDF，并检查初始溢出和修改文字后的局部样式清理。该脚本使用隔离数据和模拟 API，不改动当前打开的工程；原始图片不会加入版本管理的测试样本。

页面内编辑验收运行 `.\.venv\Scripts\python.exe scripts/verify_inline_editing.py`，检查追加内容、光标、局部粗体、中文输入法、换行、自动扩展、下方内容顺移、撤销、粘贴、保存重开及 PDF。使用隔离 API，不改动当前工程。

内容编辑与段落整理验收运行 `.\.venv\Scripts\python.exe scripts/verify_document_editing.py`，使用合成简历和隔离 API 验证单击光标、真实鼠标拖选、稳定编辑节点、Tab 切换、整理预览/取消、连续碎行与粗体合并、列表边界、重复整理、段落增长/收缩、栏目连带移动、空行/空段落、中文组合输入、纯文本粘贴、版式拖动、保存重开和 HTML/PDF。产物位于忽略版本管理的 `artifacts/document-editing/`。

独立文件验收运行 `.\.venv\Scripts\python.exe scripts/verify_standalone_html.py`，由隔离 API 导出后直接打开 `file://` 文件，不启动任何 HTTP 服务，验证文字、粗体、增减高度、换行/空行/空文字、中文输入法、纯文本粘贴、换图、两轮下载保存与重开、Ctrl+S 和无工具栏的两页 PDF。长内容打印验证末尾文字仍存在；没有外部网络请求。产物及虚构的 `可编辑简历示例.html` 位于 `artifacts/standalone-html/`。

泛化质量验收运行 `.\.venv\Scripts\python.exe scripts/verify_generalization.py --baseline --holdout`。它用浏览器生成独立的多字体、单栏/双栏、不同字号与缩放/JPEG 图片，以 DOM 真值比较文字、字体候选、字号、位置和初始溢出；`--baseline` 在内存加载 Git HEAD 的旧实现做对比，不切换代码或修改工程。报告位于 `artifacts/generalization/corpus/report.json`，逐项保留通过和失败。完整门槛为：忽略空白后的字符准确率至少 90%、字体候选命中率至少 65%、字号误差中位数不超过 12%、归一化位置误差均值不超过 1.5%，并且没有漏块和初始溢出；任一未达到时脚本返回失败，不把已生成页面当作质量通过。真实图片验收可使用 `scripts/verify_image_layout.py 图片路径 --output artifacts/独立验收目录`，生成私有对照、当前模型、可独立编辑 HTML、PDF 和质量摘要。

API 文档：<http://127.0.0.1:8765/api/docs>。数据模型：`backend/models.py` 与 `frontend/src/types.ts`。实现与验收记录见 [docs/开发进度.md](docs/开发进度.md)，依赖与模型声明见 [docs/THIRD_PARTY_NOTICES.md](docs/THIRD_PARTY_NOTICES.md)。
