# Resume Rebuilder · 简历重建工作台

根据 [开发文档.md](开发文档.md) V1.1 实现的本地首版。Python + FastAPI 负责解析、OCR、存储和导出；React + TypeScript 渲染只读对照预览，独立 HTML 提供编辑与保存。文件保存在本机 `projects/`，服务只监听 `127.0.0.1:8765`。

## 启动

本次开发已安装 Python / 前端依赖并构建界面，当前机器的 Edge 已验证能用于 PDF 导出。在此文件夹的 PowerShell 中运行：

```powershell
.\start.ps1
```

浏览器访问 <http://127.0.0.1:8765>。按 Ctrl+C 停止服务。不自动打开浏览器时使用 `.\start.ps1 -NoBrowser`。

也可以通过根目录的 Python 启动文件运行（自动使用项目虚拟环境）：

```powershell
python run.py
# 不自动打开浏览器
python run.py --no-browser
```

Windows 下可在另一个终端运行对应的停止文件（也适用于 `start.ps1` 启动的服务）：

```powershell
python stop.py
# 仅检查服务，不停止
python stop.py --check
```

重复停止会提示服务未运行。脚本核对本机服务与后端进程身份后才停止，不关闭浏览器，不删除工程文件。

换到新环境时先安装 Python 3.11～3.13、Node.js 22（建议安装 uv），再运行：

```powershell
.\setup.ps1
.\start.ps1
```

安装阶段需要下载依赖；应用运行阶段没有在线 AI、云服务、远程字体或模型下载。安装脚本默认优先使用现有 Edge/Chrome，找不到时安装项目内的 Chromium headless shell。若准备独立离线运行时，可执行 `.\setup.ps1 -BundleBrowser` 提前下载浏览器。Python 依赖和 OCR 模型必须提前安装；此版本尚未制作无需 Python/Node 的安装包。

若本机 PowerShell 执行策略禁止脚本，可从本目录使用 `powershell -ExecutionPolicy Bypass -File .\start.ps1`，仅影响该脚本进程。

## 使用

1. 点击「导入简历模板」选择 PDF、JPG、PNG、WebP；也可以拖入文件。点击「体验示例」打开两页合成简历。
2. 默认左侧原图对照、右侧「识别结果预览」。预览只读，可以选择复制文字、缩放与翻页，点击、双击、拖动和编辑快捷键不会改动简历。原生 PDF 提取文字和图形；图片/扫描 PDF 使用本地 OCR，需人工校对。
3. 点击顶部「进入 HTML 编辑」或预览提示旁的「在 HTML 中编辑」，在独立页面修改文字、使用字体格式刷、更换图片。完成后在该页保存修改后的 HTML，或从该页打印 PDF。
4. 在 HTML 编辑页修改后，点击「保存修改后的 HTML」下载新文件，或点击「打印 / 导出 PDF」。重新打开保存的 HTML 可继续编辑。
5. 工作台保留工程名称修改、保存与 Ctrl+S；首页可打开最近工程，`.rresume` 用于工程备份和迁移。原有高级调整、属性栏、绘图与段落整理已移除，空白新建入口也已移除。
6. 原始参考面板的删除按钮可永久清除参考图，简历内容与已上传图片会保留。
7. 工作台导出只包含当前工程中的内容，不包含 HTML 编辑页的独立修改。再次「进入 HTML 编辑」会从当前工程生成新文件；请继续使用已打开的编辑页或保存后的 HTML，以保留在 HTML 中的修改。

### 独立 HTML 文件的编辑与保存

导入后可以直接点击顶部「进入 HTML 编辑」，在新页面中修改简历；工作台先保存当前工程，再生成独立 HTML。也可以使用「导出 → HTML」下载文件。导出窗口默认选中 HTML，工作台仅用于只读对照预览与工程管理，简历编辑统一在 HTML 页面完成。独立页面修改后需在该页面保存 HTML，修改不会自动同步回工作台；提示区和工作台导出窗口会说明这一保存边界。

导出后直接用浏览器打开 `.html` 文件，点击文字即可输入，选中文字后点击「加粗 / 取消加粗」或按 Ctrl+B。点击图片区域选择本机 PNG/JPG/WebP；图片会嵌入文件，不依赖外部资源。顶部「文字排版」可调整当前文字块的增长方式，段落模式支持高度增减和下方内容顺移。

「格式刷（字体）」使用方法：先选中源文字（也可把光标放入源文字），单击格式刷，再拖选目标文字。复制字体名称、字号、粗体/常规、斜体和文字颜色，应用一次后自动退出；双击格式刷可连续应用，按 Esc 或再次单击按钮退出。源选区有多种样式时取第一个选中字符的字体。每次目标选区限于同一个文字块，可连续刷不同文字块或页面。支持 Ctrl+Z / Ctrl+Y 撤销重做，保存的新 HTML 保留局部字体样式。字号变化可能触发现有文字排版的换行与增高规则；对齐、背景、边框和排版模式不随格式刷复制。

格式刷用于新版独立 HTML 编辑页。更新后重新点击「进入 HTML 编辑」或重新导出 HTML；已经打开或下载的旧文件内嵌旧代码，需要重新导出。无需重新识别简历。

点击「保存修改后的 HTML」或按 Ctrl+S，浏览器会下载包含当前文字、格式和图片的新文件；打开这个新文件还可以继续编辑和再次保存。保存不会自动覆盖最初的文件。输入与新图片保留在当前页面内，关闭前请保存。文件中的修改不会自动同步回工作台工程，目前也不支持将 HTML 重新导入工程。

「打印 / 导出 PDF」调用浏览器打印，可选择另存为 PDF。编辑工具、焦点框和空图片提示不会进入打印。内容变长时屏幕上的页面随之增高，打印时每个原始页面等比缩小到其纸张尺寸；这与自动拆成更多页面不同，长文可能使字号变小。不同栏、固定尺寸和旋转文字仍需检查。

## 隐私与数据

- 导入默认保留识别出的原文，工作台仅预览；HTML 编辑文件只保存当前内容，没有原图底图、白色遮罩或旧文本覆盖层。
- PDF 源图片只读取显示位置，不解码到素材库；整页扫描图进入 OCR 路径，不生成整页头像框。
- 原始页面会渲染到 `reference/` 供对照，可能含原个人信息。点击原始参考面板的删除按钮可永久清除参考。
- `assets/` 只接收用户主动上传的新图片；图片重新编码为 PNG，保留透明度、应用 EXIF 方向并剥离元数据。
- PDF/HTML 只读取当前元素与引用的新图片，不包含原始参考、撤销历史或未引用的图片。
- 成品标题使用固定「简历」，不把来源文件名写入 HTML/PDF 元数据；工程包仍保留你当前设置的工程名称。
- HTML 编辑页的撤销历史仅存在于当前页面会话，不写入保存文件或工作台工程。
- 导出工程包可取消原始参考。工程包包含当前 JSON 与已引用的新图片；重新导入会分配新工程 ID。
- 文件上限 25MB，图片上限 3000 万像素，最多 20 页；项目包解压总量上限 100MB。路径穿越、重复路径、非法文件、非法资源和颜色/字体注入会被拒绝。
- 源文件解析在独立进程执行，超时 180 秒；错误导入不会覆盖已有工程。数据目录可通过 `RESUME_DATA_DIR` 配置，浏览器路径可通过 `RESUME_BROWSER_PATH` 配置。
- `runtime/glyph-cache/` 缓存系统字体生成的单字参考，不保存简历原文、位置、照片或源图裁片，不进入工程包或成品。缓存按字体文件状态、Pillow/FreeType 版本、浏览器版本及绘制代码隔离；损坏或不可写时重新计算，容量受限。可用 `RESUME_GLYPH_CACHE_DIR` 调整目录，`RESUME_GLYPH_CACHE=0` 禁用磁盘缓存。

## 当前边界

图片导入已增加无损字形缓存与重复计算复用，保留字体候选、字号搜索及粗体判定规则。本机同一张 1080×1515、58 行图片实测：优化前 71.8 秒，全新缓存首次 67.4 秒，跨进程命中缓存后 22.5 秒；文字、字体、字号、局部粗体、坐标和图形数据与优化前一致。首次处理新字形仍较慢，其他模板耗时取决于文字量和缓存命中率。

长页字体匹配先用代表字形判断字体，再只为选中的字体生成完整字符参考，避免密集简历触发预算后整体失去精匹配。缺失参考不混用其他栅格器，回退也执行同样的局部粗体置信度检查。数字标签按整块字重恢复，不自动猜测数字内部的混合粗体；英文字间空白可用完整字形的像素间隙辅助恢复，字母残片不作为空格依据。该修复减少误加粗，仍会漏掉部分真实局部粗体。

密集正文专项验收运行 `python scripts/verify_style_fidelity.py --dense`，覆盖常规正文、粗体前缀、普通日期与 PNG/缩放 JPEG，同时报告正常字误加粗率和真实粗体召回率。它使用虚构内容，产物在 `artifacts/typography-20261015/dense/`，失败项不会被功能测试通过覆盖。复用私有 OCR 缓存的诊断可运行 `python scripts/diagnose_typography.py 图片路径 输出目录`，不修改源工程。

已覆盖 M0～M4 的基础工作流。复杂 PDF 裁剪、曲线、遮罩、缺失字体仍需人工校正；OCR 的颜色、字体和布局估计不是精确恢复。PDF 原字体名称会保留为线索，使用系统后备字体，并估计字宽以保持原行边界；换机器后应再次检查排版。

图片/扫描页已增加像素样式重建：包括很浅的标题背景、横线/竖线、与标题带相邻的弯曲装饰和列表圆点，恢复为可编辑几何，弯曲装饰使用归一化轮廓与 CSS 多边形，不复制源图裁片。按文字墨迹高度估计字号，本机浏览器生成字形样本辅助匹配字体、整行/局部粗体与缩放后的抗锯齿；浏览器不可用或精匹配超出预算时保留本地像素估计。局部粗体按逐字符证据检测，包括正文中间的中文短语，候选字体证据不足时保守跳过。浏览器度量校准编辑器及导出宽度。局部样式只记录当前文字的索引范围，页面内编辑保留局部粗体，辅助输入框按改动映射未修改范围；选择整框字重可统一重设。不保存旧文字副本。字体细节、图标与 OCR 误读仍需要校对。

图片重建按通用像素和几何特征处理，不按来源文件名、人员姓名、特定技术词或模板坐标分支。低置信度行会在本地局部复识别，未能确认的行保留解析提示及文字悬停说明；不会把几个缺字结果强行拉伸铺满长行。中文和英文字体分别匹配，同一行共享字号；清晰证据可保留不同标题字体，页面统计仅用于消解模糊候选。样式估计失败时保留已识别的文字和位置，并提示人工校正。灰色细分隔线和不同大小的列表圆点也按几何恢复。

字体仍是本机已安装字体中的近似候选。小字号经过缩放/JPEG 压缩后会丢失字体细节，OCR 文字正确并不代表字体准确；候选不明确时，解析提示会明确说明。当前没有达到任意简历图的像素级还原，也不能把某张图片的成功验收推广到所有模板。

升级后请重启后端、刷新前端，再重新导入原图。已经保存的工程保留此前的元素数据，不会自动重跑识别或覆盖你的修改。

已有工程仍可打开预览并生成可编辑 HTML；过去保存的文字、位置、图片及段落模式继续保留。重新导入仅用于重新运行识别算法。

独立编辑页用 HTML DOM 编辑段落，页面仍按模板坐标存储；支持单页内的段落增减高度与后续内容顺移，尚非整篇文档的连续流式排版，不自动跨页重排，也不支持跨独立文字块一次删改。复杂多栏或旋转文字需逐页检查，结构性版式修改需先修改源模板再导入。超出纸张时状态栏和成品导出窗口会提示，导出前请逐页检查；工作台直接导出的 PDF 仍按原纸张边界裁切。独立 HTML 已内置编辑与保存能力，其浏览器打印会将增长后的每页内容缩小到原纸张；它不包含工程的原始参考和撤销历史。

P1 的自动候选图片区检测、多选对齐、吸附、差异叠加、批量清空、整篇跨页流式排版和安装包尚未实现。独立 HTML 支持替换已有图片区，暂不提供新增元素、拖拽定位或手动框选。

## 开发与验证

```powershell
# 后端开发
uv run uvicorn backend.main:app --host 127.0.0.1 --port 8765 --reload
# 新终端中启动前端开发服务器
cd frontend
npm run dev
```

前端开发地址为 `127.0.0.1:5173`，API 通过 Vite 代理到 8765。正式启动使用已经构建的 `frontend/dist/`，无需 npm 运行。

```powershell
.\.venv\Scripts\python.exe -m pytest -q
# 隔离数据的真实浏览器验收，无需先启动服务
.\.venv\Scripts\python.exe scripts/verify_ui.py
.\.venv\Scripts\python.exe scripts/check_runtime.py
cd frontend
npm run build
```

测试样例均为自行生成的虚构内容：`examples/native-resume.pdf`（两页原生 PDF + 合成头像）、`chinese-resume.png`（中文截图）、`scanned-resume.pdf`（整页扫描）、`repeated-photo.pdf`（同一图像资源多位置）。生成脚本为 `scripts/create_samples.py`。这些样例可以自由用于本项目的验收。

真实浏览器脚本验证导入、只读预览、分页、独立 HTML 改字换图、保存重开、打印 PDF 与工程包隔离；截图和导出测试文件保存在忽略版本管理的 `artifacts/`。网络验证是禁止 OCR 网络调用、阻断导出页面网络请求、检查前端外部请求；尚未进行操作系统断网开关的人工测试。

指定图片的样式与整页浏览器验收可运行 `.\.venv\Scripts\python.exe scripts/verify_image_layout.py "图片路径.png"`，生成私有原图对照、编辑器截图及 PDF，并检查初始溢出与独立 HTML 编辑保存。该脚本使用隔离数据和模拟 API，不改动当前打开的工程；原始图片不会加入版本管理的测试样本。

工作台与 HTML/PDF 共用有效字号：文字以至少 100px 的 CSS 字号配合布局缩放显示，保留文档中的原字号和文本框宽度，避免小字被浏览器最小字号抬高后行尾掉字。输入测量、段落重排与溢出检查也计入布局缩放。已有工程刷新页面即可使用，无需重新导入；更新后端后应重新打开或导出独立 HTML，已经下载的旧文件不会自动更新。文字单位专项运行 `.\.venv\Scripts\python.exe scripts/verify_text_units.py`，比较最小字号 0/10/12/16/24px 下只读预览、静态导出与可编辑 HTML 的真实字号、逐字行数及文本框宽度，并检查多行文本和固定框越界；`--pixels` 验证像素单位页面。产物默认在 `artifacts/text-units/`；可用 `--project 工程路径 --output 独立目录` 只读检查私有工程。该检查不代替 OCR 字体、字号和粗体推断质量验收。

独立文件验收运行 `.\.venv\Scripts\python.exe scripts/verify_standalone_html.py`，由隔离 API 导出后直接打开 `file://` 文件，不启动任何 HTTP 服务，验证文字、粗体、增减高度、换行/空行/空文字、中文输入法、纯文本粘贴、换图、两轮下载保存与重开、Ctrl+S 和无工具栏的两页 PDF。长内容打印验证末尾文字仍存在；没有外部网络请求。产物及虚构的 `可编辑简历示例.html` 位于 `artifacts/standalone-html/`。

泛化质量验收运行 `.\.venv\Scripts\python.exe scripts/verify_generalization.py --baseline --holdout`。它用浏览器生成独立的多字体、单栏/双栏、不同字号与缩放/JPEG 图片，以 DOM 真值比较文字、字体候选、字号、位置和初始溢出；`--baseline` 在内存加载 Git HEAD 的旧实现做对比，不切换代码或修改工程。报告位于 `artifacts/generalization/corpus/report.json`，逐项保留通过和失败。完整门槛为：忽略空白后的字符准确率至少 90%、字体候选命中率至少 65%、字号误差中位数不超过 12%、归一化位置误差均值不超过 1.5%，并且没有漏块和初始溢出；任一未达到时脚本返回失败，不把已生成页面当作质量通过。真实图片验收可使用 `scripts/verify_image_layout.py 图片路径 --output artifacts/独立验收目录`，生成私有对照、当前模型、可独立编辑 HTML、PDF 和质量摘要。

无损字形专项运行 `.\.venv\Scripts\python.exe scripts/verify_glyph_equivalence.py --baseline-ref 优化前提交`，比较 4032 组 Pillow 字形在冷/热缓存下的原始像素及 3024 组浏览器字形；基线默认 `HEAD`，也可指定优化前提交。报告在 `artifacts/glyph-equivalence/`，缓存损坏、环境失效与容量边界另有后端回归。
